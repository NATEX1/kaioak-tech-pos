# Phase 7 — ตรวจสอบประวัติเคลม และ Serial/Warranty Tracking

> สถานะ: **เสร็จสิ้น พร้อมตรวจ** — ต่อเนื่องจาก Phase 6; ทุกฟีเจอร์ด้านการตรวจสอบประวัติซื้อ, การติดตาม Serial รายชิ้น, และการคำนวณวันหมดประกันทำงานได้อย่างสมบูรณ์

## 1. สรุปสิ่งที่ทำเสร็จ

- **ระบบติดตาม Serial รายชิ้น (Unit-level Serial Tracking):**
  - บันทึกและผูก `ProductSerial` เข้ากับรายการขายในบิล (`BillItemSerial`)
  - เมื่อบิลขายได้รับการอนุมัติ (`APPROVED`): อัปเดตสถานะ Serial จาก `IN_STOCK` เป็น `SOLD` บันทึก `soldAt`, `warrantyStartAt`, และคำนวณ `warrantyEndAt` อัตโนมัติจากระยะเวลารับประกันของสินค้า (เดือน)
  - เมื่อบิลถูกยกเลิก (`VOIDED`): คืนสถานะ Serial กลับเป็น `IN_STOCK` และล้างวันเริ่ม-หมดประกัน พร้อมระบุเวลาคืนใน `BillItemSerial.releasedAt`
- **ระบบคำนวณและตรวจสอบระยะเวลารับประกัน (Warranty Calculation Engine):**
  - ฟังก์ชันคำนวณวันหมดประกันแม่นยำ รองรับปีอธิกสุรทิน (Leap Year) และวันสิ้นเดือน (`src/lib/warranty-calculations.ts`)
  - คำนวณสถานะ `IN_WARRANTY` (อยู่ในประกัน พร้อมจำนวนวันคงเหลือ), `OUT_OF_WARRANTY` (หมดประกัน พร้อมจำนวนวันที่หมดไปแล้ว), `IN_STOCK` (ยังไม่ขาย), และ `NO_WARRANTY`
- **ระบบตรวจสอบก่อนเคลมแบบเรียลไทม์ (Live Pre-Claim Verification):**
  - ทำงานในหน้าเปิด/แก้ไขบิล (`/bills/new` และ `/bills/[id]/edit`) เมื่อเลือกประเภทบิลเป็น **บิลเคลมสินค้า (`WARRANTY_CLAIM`)**
  - เมื่อเลือกลูกค้า + สินค้า หรือระบุ Serial ระบบจะตรวจสอบประวัติการซื้อจริงของลูกค้ารายนี้จากบิลที่สถานะ `APPROVED` / `PAID` ทันที (Live Auto-check)
  - แสดงผลลัพธ์ผ่าน Interactive Card:
    - ✅ **พบประวัติและอยู่ในประกัน:** แสดงเลขบิลเดิม, วันที่ซื้อ, วันหมดประกัน, จำนวนวันคงเหลือ
    - ⚠️ **พบประวัติแต่หมดประกันแล้ว:** แสดงเลขบิลเดิม, วันหมดประกัน, พร้อมคำเตือนเรื่อง Admin Override
    - ❌ **ไม่พบประวัติการซื้อของลูกค้ารายนี้:** แสดงคำเตือนสีแดงเด่นชัดว่าต้องได้รับการอนุมัติเป็นกรณีพิเศษจาก Admin
- **ระบบค้นหาย้อนหลังจาก Serial Number (Reverse Lookup):**
  - ปุ่ม "ค้นหาจาก Serial" ในฟอร์มบิลเคลม: สแกนหรือพิมพ์ Serial แล้วกดค้นหา ระบบจะตรวจสอบว่าใครเป็นผู้ซื้อ และเป็นสินค้าอะไร พร้อม Auto-fill ลูกค้าและสินค้าให้อัตโนมัติทันที
- **หน้าเครื่องมือตรวจสอบประกัน (`/warranty`):**
  - เพิ่มเมนู **"ตรวจสอบประกัน"** ใน Sidebar Navigation หลัก (`AppNav`)
  - สแกนบาร์โค้ดหรือค้นหา Serial ได้โดยตรงโดยไม่ต้องเลือกลูกค้าก่อน
  - แสดงข้อมูลสินค้า, ข้อมูลผู้ซื้อ (ลูกค้า), บิลที่ซื้อ, สถานะประกัน, และประวัติการเคลมเดิมของ Serial นั้น
  - ปุ่มด่วน **"เปิดบิลเคลมสำหรับสินค้านี้ทันที"** ลิงก์ตรงไปหน้าเปิดบิลเคลมพร้อม pre-fill ลูกค้า, สินค้า, Serial ให้อัตโนมัติ
- **หน้ารายละเอียดลูกค้า (`/customers/[id]`):**
  - เพิ่มการ์ด **"รายการสินค้าที่เคยซื้อ & ประกัน"** แสดงสินค้าและ Serial ทั้งหมดที่ลูกค้าเคยซื้อจริง พร้อมสถานะประกันและปุ่ม "เปิดเคลม"
- **หน้ารายละเอียดสินค้า (`/inventory/products/[id]`):**
  - ในตาราง Serial Number สามารถคลิกที่หมายเลข Serial เพื่อข้ามไปตรวจสอบสถานะประกันใน `/warranty` ได้ทันที
- **Workflow การอนุมัติและการ Override ของ Admin:**
  - ในบิลเคลม หากผลการตรวจเป็น `FOUND_OUT_OF_WARRANTY` หรือ `NOT_FOUND` ระบบจะไม่อนุญาตให้อนุมัติบิล เว้นแต่ Admin จะระบุเหตุผลอนุมัติเป็นกรณีพิเศษ (`adminOverrideReason`) อย่างน้อย 3 ตัวอักษร
  - บันทึก Snapshot ผลการตรวจ และ Audit Log ทุกขั้นตอน

## 2. Route และ UI ที่เพิ่ม / ปรับปรุง

| Route | หน้าที่ |
|---|---|
| `/warranty` | หน้าตรวจสอบประกันและค้นหาย้อนหลังจาก Serial Number |
| `/api/warranty/check` | API Endpoint สำหรับตรวจสอบประกันและค้นหาประวัติการซื้อ |
| `/bills/new` | รองรับ Query Params (`billTypeCode`, `productId`, `serialNumber`, `customerId`) และ Interactive Pre-claim Card |
| `/customers/[id]` | เพิ่มแท็บ/ตารางรายการสินค้าที่เคยซื้อ พร้อม Serial และสถานะประกัน |
| `/inventory/products/[id]` | เชื่อมโยง Serial Number ไปยังหน้าตรวจสอบประกัน |

## 6. วิธีทดสอบด้วยมือ (Manual Walkthrough)

1. **เข้าสู่ระบบ:**
   - เข้าที่ `http://localhost:3000/login` ด้วย `admin@compos.local` หรือ `tech1@compos.local`
2. **ทดสอบเครื่องมือตรวจสอบประกัน (`/warranty`):**
   - คลิกเมนู **"ตรวจสอบประกัน"** ใน Sidebar
   - ลองพิมพ์ Serial ที่ไม่มีในระบบ เช่น `TEST-9999` → แสดงกล่องเตือนสีแดง "ไม่พบข้อมูล Serial"
   - ลองพิมพ์ Serial ที่มีอยู่ในสต๊อก เช่น `CPU-...` หรือสินค้าที่เคยรับเข้า → แสดงสถานะสีฟ้า "ยังไม่ถูกขาย (อยู่ในสต๊อก)"
3. **ทดสอบโปรไฟล์ลูกค้า (`/customers`):**
   - เลือกลูกค้าคนใดคนหนึ่งเพื่อดูโปรไฟล์
   - เลื่อนลงมาที่การ์ด **"รายการสินค้าที่เคยซื้อ & ประกัน"**
   - ตรวจดูรายการสินค้า, วันหมดประกัน, และ Badge สถานะประกัน
   - คลิกปุ่ม **"เปิดเคลม"** ที่รายการสินค้า → ระบบจะพาไปยังหน้า `/bills/new` โดยเลือกประเภทบิลเคลม และเลือกลูกค้า + สินค้าให้อัตโนมัติ
4. **ทดสอบ Interactive Pre-claim Check ในฟอร์มบิล (`/bills/new`):**
   - เลือกประเภทบิลเป็น **"บิลเคลมสินค้า"**
   - สังเกตการ์ด **"ข้อมูลการเคลม"** จะปรากฏขึ้นมา
   - หากเลือกลูกค้าและสินค้าที่ลูกค้าเคยซื้อจริง → จะปรากฏกล่องสีเขียวอัตโนมัติแจ้งว่า **"พบประวัติการซื้อ — ยังอยู่ในระยะเวลารับประกัน"** พร้อมแสดงเลขบิลเดิมและวันหมดประกัน
   - หากเลือกลูกค้าและสินค้าที่ลูกค้าไม่เคยซื้อ → จะปรากฏกล่องสีแดงแจ้งเตือนว่า **"ไม่พบประวัติการซื้อของลูกค้ารายนี้จากทางร้าน"** และเตือนว่าต้องใช้ Admin Override
   - หากพิมพ์ Serial ในช่อง "Serial ที่เคลม" แล้วกดปุ่ม **"ค้นหา"** → ระบบจะทำ Reverse Lookup และช่วยเลือกลูกค้า/สินค้าให้อัตโนมัติ
